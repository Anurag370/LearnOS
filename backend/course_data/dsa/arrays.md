# Arrays

## Definition

An array is a linear data structure that stores elements
of the same type in contiguous memory locations.

## Properties

- Elements are accessed using an index.
- Indexing generally starts from 0.
- Random access takes O(1) time.

## Example

int arr[5] = {10, 20, 30, 40, 50};

## Time Complexity

Access: O(1)
Search: O(n)
Insertion: O(n)
Deletion: O(n)
